# Terimler

**Türkçe** · [English](../12-glossary.md)

| Terim | Anlam |
|---|---|
| Zarf | sihir ‖ RSA ile sarılmış anahtar ‖ nonce ‖ AES-GCM şifreli metin ‖ tag |
| Cihaz kimliği | 6 parçalı donanım parmak izi (`‖1;…`) |
| `ht` | cihaz kimliği + sürüm üzerinden SHA-1 bütünlük alanı |
| `htt`, `gg` | ek bütünlük alanları (doğrulama kesin, türetim bilinmiyor) |
| Oracle | gerçek sunucuya istek atıp durum kodunu hüküm olarak okumak |
| Sanal bölüm | MBA ile gizlenmiş, sanallaştırılmış kod bölümü |
| Bağlam (context) | sanal yazmaç dosyası + bayraklar (536 bayt) |
| Dağıtıcı | dolaylı dal hedefini hesaplayan kod; burada yazmaca bağlı |
| MBA | karışık boolean-aritmetik ifade |
| Ürün oturumu | Riot Client'ın başlatılan ürün için tuttuğu sahiplik kaydı |
| Attestation | çekirdek modunda üretilen donanım kanıtı |
